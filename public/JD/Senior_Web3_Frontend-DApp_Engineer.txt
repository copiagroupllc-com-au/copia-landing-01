Senior Web3 Frontend / DApp Engineer
Location: Australia / Remote
Employment Type: Full-time
Department: Engineering
Level: Senior
About Copia Group
Copia Group is building a Web3 fintech and payments platform — essentially “Stripe for Web3.”
Our mission is to make blockchain payments and financial products as simple, reliable, and intuitive as modern fintech applications.
As we expand internationally, including our planned Australia presence, we're looking for a Senior Web3 Frontend / DApp Engineer to help build the user-facing layer of our Web3 payments ecosystem.
About the Role
We're looking for a senior frontend engineer who combines strong React/TypeScript skills with hands-on Web3 experience.
You'll build production-grade DApps and user experiences that interact directly with blockchain networks, smart contracts, wallets, and payment infrastructure.
You'll work closely with Product Designers, Backend Engineers, Smart Contract Engineers, and DevOps/Infrastructure teams to turn complex blockchain functionality into simple, fast, and secure user experiences.
This is a hands-on role with significant ownership over frontend architecture and the Web3 user experience.
Key Responsibilities
* Build and maintain production-grade Web3 applications and DApps.
* Develop modern frontend applications using React and TypeScript.
* Integrate wallets, smart contracts, blockchain networks, and Web3 APIs.
* Build intuitive flows for payments, transactions, deposits, withdrawals, and wallet interactions.
* Design robust transaction-state handling, including pending, confirmed, failed, and rejected transactions.
* Integrate and interact with EVM-compatible smart contracts.
* Build reusable frontend components and Web3 interaction libraries.
* Work closely with smart-contract engineers to integrate contract interfaces safely.
* Implement responsive interfaces based on Figma designs.
* Optimize frontend performance and application scalability.
* Implement secure wallet connection and transaction-signing flows.
* Handle blockchain-specific UX challenges such as gas estimation, network switching, confirmations, and transaction failures.
* Write unit, integration, and end-to-end tests.
* Participate in frontend architecture and technical design decisions.
* Contribute to CI/CD and production deployment workflows.
* Monitor and troubleshoot frontend and Web3 production issues.
* Help establish frontend engineering standards and best practices.
* Mentor junior and mid-level engineers as the team grows.
